## Upload Test Norms

Uploads test norms to existing norms.

### Access Path

- `Test Norms` > `Upload Test Norms`

### Required Inputs

- Norm name
- Account name related to the assessment
- Assessment name
- File upload based on the required format

### How To Use

1. Enter the required data and upload the file in the required format.
2. Select `Next`.
